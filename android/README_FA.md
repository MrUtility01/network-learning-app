# اندروید — دانشنامه جامع شبکه (۰.۴.۳+)

## مسیر ۱: PWA (سریع)
1. روی ویندوز `run_windows.bat` را اجرا کن.
2. IP رایانه را با `ipconfig` بگیر.
3. در Chrome اندروید برو به `http://IP:8000`
4. منو → Add to Home screen.

## مسیر ۲: APK با Android Studio
1. پوشهٔ `android/` را در Android Studio باز کن.
2. `DEFAULT_SERVER` را در MainActivity به IP خودت تغییر بده.
3. Build APK.

سرور FastAPI باید روی ویندوز روشن باشد.
